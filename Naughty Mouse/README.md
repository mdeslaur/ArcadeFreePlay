The python scripts in this directory will decrypt and patch the two
Naughty Mouse romsets in MAME so they can run on real Pac-Man hardware.

nmouse_decrypt.py decrypts and patches Naughty Mouse (set 1) (nmouse).  
nmouseb_decrypt.py decrypts and patches Naughty Mouse (set 2) (nmouseb).
